# 第11章：综合运用

来源：原书第11章；已核对图11.12。用途：结合多时间框架、整理与价格形态，形成统一的观察过程。

## 核心思想

多个时间框架提供同一市场的不同聚合视角。较慢图给背景，主图组织当前判断，较快图给细节。它们不是三份独立证据，也不能把三个图的同一事件计为三次统计确认。

## 框架与操作

### 三周期观察

原书示例使用5／15／30分钟，15分钟为主要交易图；也给出30／60／240分钟组合。30分钟同一事件在15分钟中分为两柱、5分钟中分为六柱。先对齐时间与会话，再比较，不能拿错位窗口拼接。

1. 慢周期：定位主导方向、整理区、前方障碍。
2. 主周期：描述当前序列和需要判断的情景。
3. 快周期：观察主要柱内的推进、拒绝和活动变化。
4. 冲突时：分别保留判断，缩小结论范围，等待主周期与结构证据。

反转线索可能先在快周期出现，随后扩大；也可能只是局部噪声，未传到慢周期。不能把这个“涟漪”比喻当作所有反转必经的时序。日／周等其他组合属于具体应用选择，应说明与用户期限的关系。

### 形态与量价确认

| 形态 | 可观察结构 | 情景与确认 |
|---|---|---|
| 下降三角 | 下界相对固定，反弹高点下降 | 下行倾向候选；仍等向下离开及量价回应 |
| 上升三角 | 上界相对固定，回落低点抬升 | 上行倾向候选；仍等向上离开及量价回应 |
| 三角旗／收缩结构 | 高点下降、低点抬升 | 方向未定，等实际突破 |
| 三重顶 | 上方同区域多次受阻 | 拒绝或成功突破两种情景并存 |
| 三重底 | 下方同区域多次收回 | 承接或向下失守两种情景并存 |

形态不是独立买卖规则。整理、供需线索、突破位置、回测和更大背景一起构成判断。即使三个顶都在同区域，也不能仅因第三次触碰就预告下跌。

### 支点缺失时

原书英镑／美元小时图出现高位支点，但没有完美低位支点。作者用实际价格反应补画下界。这不是允许随意画线：应列出至少可观察的停留与反转依据，保留“候选区”状态，等后续验证。辅助指标与肉眼判断都不能制造不存在的数据。

## 关键概念

- 主周期：用户分析和计划执行的中心。
- 基准周期：较慢背景视角。
- 时间对齐：不同图覆盖同一事件范围。
- 顺／逆势：相对于指定背景周期定义。
- 收缩：上下边界相向，方向尚未定。
- 结构确认：价格离开并表现出延续或保持。

## 心智模型

1. **望远镜变焦**：同一场景从远近观察，不是增加独立样本。
2. **池塘涟漪**：快周期变化可能扩大，也可能消散。
3. **导航双系统**：支点帮助定位，原始价格和量仍需检查。

## 反模式

- 三个周期重复同一事件，就给三倍信心。
- 在较快图看到反弹便宣布较慢图转牛。
- 缺少支点时假造指标数值，或者无依据改变边界。
- 根据三角名称提前固定突破方向。

## 重构例子

图11.12较慢图的高量上影结构，在较快图中表现为先上攻再受阻的多个柱。重构：慢图指出净推进不足；快图解释这个结果由哪些阶段构成。若用户只提供主图，说明未能核对慢背景，不假装完成三周期分析。若慢图仍上涨、快图转弱，报告“短期弱势，尚未确认更大反转”。

## 要点与连接

- 选周期前先确认用户期限。
- 保留冲突，别硬凑一致。
- 形态提供情景，实际量价决定更新。
